The agent-stop guard installer checks each systemd unit for a KillMode that would let child processes survive a stop. Two cases go wrong. First, when a unit file cannot be read, the installer acts as if the file were empty and installs the guard anyway. Second, a KillMode line split over several lines with a trailing backslash is not understood, so a unit that really uses KillMode=process is treated as safe. Make the installer read units the way systemd does, and make it fail loudly instead of writing anything when a file cannot be read.
