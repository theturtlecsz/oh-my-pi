Project trust follows linked git worktrees: a worktree of a trusted repository counts as trusted. A directory I made by hand, with a .git file that only points at a trusted repository or at a worktree admin directory of it, is also treated as trusted, so it can run project config and extensions without a prompt. Only genuine linked worktrees may inherit trust. Also, a trusted-projects file with a wrong format marker should not be read as a trust list.
