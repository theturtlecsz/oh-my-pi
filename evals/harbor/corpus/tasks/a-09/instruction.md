Our advisor supervision tallies are wrong when a note is delivered as a pending proposal. The gate counts it as delivered immediately, so if the proposal is displaced and never routed, the delivered total includes a note the user never saw. Track a pending delivery by its normalized note and count it only when it is routed, keeping the class it was admitted under. A displaced pending note, or a live delivery of that same note, must be dropped from the pending queue so it is not counted again. The delivered sum must stay equal to the number of notes actually routed after every operation.
