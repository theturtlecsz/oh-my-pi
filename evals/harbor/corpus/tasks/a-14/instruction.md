Add the project egress policy store and its migration. Migration 0033 owns the project egress policy table and the append-only egress records table, one active policy row per project, with the application role allowed to change only the active flag. The store must insert a new policy version once the change against the active row is authorized, clear the active flag on the row it replaces, load the active policy by compiling it with the active standing policies, and never let a project clone's own files contribute to the compiled policy.
