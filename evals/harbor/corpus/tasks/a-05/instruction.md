Our autoresearch sessions need a way to bring in results that were produced by a managed campaign instead of by the local loop. Add an `import-managed` command that reads a managed results file and records each accepted row as an unverified run in the active session, keeping its metric and direction. Rows that are malformed, point at an incompatible direction, or fail validation must be rejected and reported, and a row already imported must not be imported twice. The notification must report how many rows were imported, rejected, incompatible, and skipped.
