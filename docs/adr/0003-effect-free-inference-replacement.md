# Bounded replacement of uncertain effect-free inference

Owner decision G6 permits a separately reserved replacement only when the original operation demonstrably cannot cause tool or external effects beyond inference resource consumption. The original outcome and usage remain unknown with conservative holds; all attempts share the existing milestone budget, and downstream arbitration accepts at most one logical result, including after late or duplicate returns. This avoids a permanent inference stall when a provider cannot report the original outcome, without relaxing reconciliation for tool-capable workers, Git/database/deployment/instrument effects or native authority.

The trade-off is possible duplicate inference cost for bounded progress; it is never a claim of exactly-once provider execution or a free/absent first request. Capability enforcement, reservation, cancellation, late-result quarantine and one-result arbitration require implementation and qualification before activation. This decision supplies no numeric budget, live grant, provider switch or permission bypass.
